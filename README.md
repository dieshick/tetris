# Тетрис

Классический Тетрис на Python + [pygame-ce](https://pyga.me/). Учебный проект.

## Установка

Нужен Python 3 (проверено на 3.14).

```bash
python3 -m venv .venv            # создать виртуальное окружение
source .venv/bin/activate        # включить его (делать в каждом новом терминале)
pip install -r requirements.txt  # установить pygame-ce и pytest
```

## Запуск

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | сдвиг влево / вправо |
| ↑ | поворот |
| ↓ | мягкий сброс (+1 очко за клетку) |
| Пробел | жёсткий сброс (+2 очка за клетку) |
| R | начать заново (после конца игры) |
| Esc | выход |

## Правила счёта

- Линии за раз: 1 — 100, 2 — 300, 3 — 500, 4 — 800 очков, умножается на уровень.
- Каждые 10 линий — новый уровень, фигуры падают быстрее.

## Тесты

```bash
pytest
```

## Устройство проекта

| Файл | Что делает |
|---|---|
| `pieces.py` | 7 фигур, поворот, класс `Piece` |
| `board.py` | поле 10×20: столкновения, фиксация, очистка линий |
| `game.py` | правила: движение, сбросы, очки, уровни, конец игры |
| `renderer.py` | рисует состояние игры (только читает его) |
| `main.py` | окно, главный цикл, клавиши |

Логика (`pieces`, `board`, `game`) не знает про pygame — поэтому её легко тестировать.
Данные идут в одну сторону: клавиши → `Game` → `renderer`.
