# Тетрис Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Классический Тетрис на Python + pygame-ce как учебный проект для новичка.

**Architecture:** Логика (`pieces.py`, `board.py`, `game.py`) не знает про pygame и покрыта тестами pytest. `renderer.py` только рисует состояние `Game`, `main.py` связывает клавиши, время и отрисовку. Поток данных: клавиши → `Game` → `renderer`.

**Tech Stack:** Python 3.14, pygame-ce, pytest.

**Spec:** `docs/superpowers/specs/2026-09-28-tetris-design.md`

## Global Constraints

- Автор — новичок: простой код, **подробные комментарии на русском**, docstring у каждой функции/класса. Без type hints, dataclasses, наследования, декораторов.
- Модули лежат в корне проекта (не пакет); импорты вида `from board import Board`.
- `pieces.py`, `board.py`, `game.py` **не импортируют pygame**.
- Поле: `WIDTH = 10`, `HEIGHT = 20`, строка 0 — верхняя; пустая клетка `None`, занятая — буква фигуры.
- Очки за линии: `{0: 0, 1: 100, 2: 300, 3: 500, 4: 800}` × уровень; мягкий сброс +1, жёсткий +2 за клетку.
- Уровень `1 + lines // 10`; `fall_interval = max(100, 800 - (level - 1) * 70)` мс.
- Окно 500×600: клетка 30 px, поле 300×600 слева, панель 200 px справа, заголовок «Тетрис».
- Каждая задача пишется по TDD: падающий тест → код → зелёные тесты → коммит.
- Все команды выполняются из корня проекта с активированным `.venv` (`source .venv/bin/activate`).

## Review Focus

1. Поворот вертикальной I у левой стенки, где сдвига на 1 не хватает: поворот отменяется, фигура не меняется, без исключений → тест в Task 4.
2. Огромный `dt` в `update` (окно перетаскивали несколько секунд): цикл падения завершается, фигуры фиксируются, при game over цикл останавливается → тест в Task 5.
3. Очистка несмежных строк (17 и 19 заполнены, 18 нет): строки сдвигаются корректно → тест в Task 3.
4. `hard_drop`, когда фигуре некуда падать: 0 очков, фигура фиксируется на месте → тест в Task 4.
5. Команды и `update` во время game over ничего не меняют → тест в Task 5.
